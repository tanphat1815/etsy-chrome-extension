# Teeinblue x Etsy helper – Order syncing

```bash
## Install
npm install

## Clean
npm run lint             # show logs only
npm run lint:fix         # show logs and fix
npm run lint:fix:strict  # show logs and fix strict

npm run build            # output: dist/
npm run build:samples    # build + include samples/
npm run build:obf        # build + strong obfuscation (internal use)
npm run zip              # dist/ -> extension.zip
npm run release          # build + zip (for upload)
npm run release:obf      # build:obf + zip (internal use)
```

# Use `dist` for uploading package
